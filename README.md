# 🏆 نظام مسابقة العادات اليومية

نظام احترافي متكامل لإدارة مسابقات العادات اليومية بين عدة متسابقين، مع مسير (إدمن) للإشراف وتوزيع المكافآت.

## 🚀 التحديثات الجديدة

### ⚡ تحسينات قاعدة البيانات (v2.0)
- 🔄 **مزامنة تلقائية** كل دقيقتين مع Google Sheets
- 📦 **ذاكرة مؤقتة ذكية** (Caching) لتحميل فوري
- 🎯 **مؤشر حالة مباشر** (Online/Offline/Syncing)
- 💾 **حفظ مزدوج** (Google Sheets + localStorage)
- ⚡ **أداء محسّن** مع معالجة أخطاء متقدمة

### 🔗 نظام الدخول المباشر
- 📱 **روابط مباشرة** لكل متسابق
- ⚡ **دخول بنقرة واحدة** بدون كتابة الاسم
- 🔗 **مشاركة سهلة** للروابط الشخصية

## 🚀 البدء السريع

### الطريقة 1: بدون Google Sheets (محلي)

1. افتح ملف `index.html` في المتصفح
2. اختر دورك (مسير أو متسابق)
3. سجل الدخول:
   - **المسير**: كلمة المرور `admin123`
   - **المتسابقون**: فقط أدخل اسمك
4. ابدأ المنافسة!

### الطريقة 2: مع Google Sheets (سحابي)

1. اتبع دليل الإعداد في [GOOGLE_SHEETS_SETUP.md](GOOGLE_SHEETS_SETUP.md)

## 📊 كيف يعمل النظام؟

### نظام النقاط
- كل عادة لها عدد نقاط محدد
- عند إكمال العادة، تُضاف النقاط للمتسابق
- المسير يمكنه منح نقاط إضافية كمكافآت

### السجل التفصيلي

#### للمتسابق:
- يظهر له سجل تفصيلي بكل نشاط قام به
- مرتب حسب التاريخ (آخر 7، 14، 30، أو 60 يوم)
- يعرض:
  - العادات التي أكملها
  - الوقت الذي أكمل فيه كل عادة
  - النقاط المكتسبة
  - المكافآت المستلمة

#### للمسير:
- سجل شامل لجميع الأنشطة في المسابقة
- مجمّع حسب التاريخ
- مقسّم حسب المتسابقين
- يعرض:
  - من قام بماذا ومتى
  - النقاط المكتسبة/المفقودة
  - المكافآت الممنوحة
  - الإحصائيات اليومية

### السلسلة (Streak)
- يتم حساب عدد الأيام المتتالية التي أكمل فيها المتسابق جميع عاداته
- تظهر في الإحصائيات

### الترتيب (Leaderboard)
- ترتيب المتسابقين حسب النقاط
- تحديث فوري
- ميداليات للأوائل (🥇🥈🥉)

## 🎮 كيفية الاستخدام

### كمتسابق:

1. **تسجيل الدخول**
   - أدخل اسمك
   - إذا كان أول مرة، سيُنشأ حساب لك تلقائياً

2. **تتبع العادات**
   - اضغط على ✖ لتحويلها إلى ✔ عند الإكمال
   - شاهد النقاط تتزايد
   - تابع تقدمك اليومي

3. **إضافة عادات مخصصة**
   - اضغط "إضافة عادة"
   - اختر الأيقونة، الاسم، الوصف، والنقاط
   - ستظهر في قائمتك الشخصية

4. **متابعة السجل**
   - راجع سجلك الأسبوعي المرئي
   - افتح السجل التفصيلي لرؤية كل نشاط

5. **المنافسة**
   - راقب ترتيبك بين المتسابقين
   - حاول الحفاظ على السلسلة

### كمسير:

1. **تسجيل الدخول**
   - كلمة المرور: `admin123`

2. **إضافة متسابقين**
   - اضغط "+ إضافة متسابق"
   - أدخل الاسم

3. **إدارة العادات الافتراضية**
   - أضف عادات ستظهر لجميع المتسابقين الجدد
   - احذف أو عدّل العادات الموجودة

4. **منح المكافآت**
   - اختر المتسابق
   - أدخل عنوان المكافأة
   - حدد عدد النقاط
   - اضغط "منح المكافأة"

5. **مراقبة الأداء**
   - راجع الإحصائيات العامة
   - تصفح الترتيب
   - اطلع على تفاصيل كل متسابق
   - راجع السجل التفصيلي للمسابقة

## 🎨 التخصيص

### تغيير كلمة مرور المسير:

في `data.js`، غيّر:
```javascript
admin: {
    password: 'admin123'  // غيّر هنا
}
```

### تغيير العادات الافتراضية:

في `data.js`، عدّل:
```javascript

    {
        id: 'water',

        name: 'شرب الماء',

        points: 10
    },

]
```

في `style.css`، عدّل:
```css
:root {
    --primary-color: #6366f1;
    --success-color: #10b981;
    --warning-color: #f59e0b;
    /* ... المزيد */
}
```
